## Publicação gratuita
Para GitHub Pages, verifique a elegibilidade do plano para o repositório privado. No plano gratuito pessoal, o caminho usual exige um repositório público. A mudança de visibilidade expõe todos os arquivos e histórico: revise antes de realizar.
Em Settings > Pages, selecione Deploy from a branch, branch main e pasta / (root), e salve. Use o endereço efetivamente exibido pelo GitHub após a publicação.
Alternativa: conecte este repositório privado a uma hospedagem estática que aceite o seu plano e publique a pasta raiz, sem comando de build.

## Conteúdo e privacidade
